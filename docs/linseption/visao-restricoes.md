# Visão do Produto e Restrições (MVP)

| Categoria | Descrição |
| --- | --- |
| É | É um aplicativo mobile. É voltado para comerciantes ambulantes e clientes. Para o público geral. Comércio local. |
| Não É | Site web. App de relacionamento. Não é Zap, Facebook ou Insta. Cassino. Ifood. Zé Delivery. |
| Faz | Compras. Vendas. Divulga os produtos. Chat de conversa entre cliente e vendedor. Gera um link PIX. Sugere conteúdos. Exibe o endereço estático, ponto de referência em texto ou redireciona para o Google Maps externo no perfil do vendedor. |
| Não Faz | Trocas. Entrega. Não possui mapa interativo interno. Não faz rastreamento GPS em tempo real (estilo Uber). |
