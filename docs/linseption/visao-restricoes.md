# Visão do Produto e Restrições (MVP)

| Categoria | Descrição |
| --- | --- |
| É | É um aplicativo mobile. Tem um feed estilo rede social focado nas postagens de produtos/lanches dos comerciantes. É voltado para comerciantes ambulantes e clientes. Para o público geral. Comércio local. |
| Não É | Site web. App de relacionamento. Não é Zap, Facebook ou Insta (mesmo tendo feed, comentários e chat). Cassino. Ifood. Zé Delivery. |
| Faz | Compras. Vendas. Divulga os produtos através do feed. Permite comentários nas fotos/postagens. Tem uma aba de chat para conversa direta entre cliente e vendedor. Gera um link PIX. Sugere conteúdos. Exibe perfis completos do comerciante (foto, bio, telefone e nome). Exibe o local de venda no perfil (endereço estático, ponto de referência em texto ou redireciona para o Google Maps externo) para o cliente avaliar se vale a pena ir buscar o produto no local. |
| Não Faz | Trocas. Entrega (não há transporte do produto até o cliente). Não possui mapa interativo interno. Não faz rastreamento GPS em tempo real (estilo Uber). Não processa pagamento por outro meio além do PIX. |
